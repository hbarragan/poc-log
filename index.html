REST API

API para consultar logs desde IA o herramientas externas.

Endpoints JSON locales para fuentes, busquedas, estadisticas y fichero efectivo.

OpenAPI JSON
GET

/api/ai/sources

Lista fuentes configuradas, path, estado y fichero resuelto.

curl http://127.0.0.1:2500/api/ai/sources
POST

/api/ai/search

Busca texto y niveles en una o varias fuentes.

{
  "sourceIds": ["symcont-pharmasuite-api"],
  "query": "exception",
  "levels": ["error", "fatal"],
  "tail": 500
}
POST

/api/ai/stats

Cuenta lineas por nivel para dashboards o agentes.

{
  "sourceIds": ["symcont-pharmasuite-api"]
}
GET

/api/ai/source/{id}/latest

Devuelve el fichero que se esta leyendo. Si el path es carpeta, devuelve el ultimo modificado.

curl http://127.0.0.1:2500/api/ai/source/symcont-pharmasuite-api/latest

MCP

Servidor MCP local para agentes compatibles con Anthropic MCP.

Endpoint HTTP JSON-RPC en /mcp. Expone herramientas para listar, buscar y contar logs.

POST

Endpoint MCP

URL local:

http://127.0.0.1:2500/mcp

URL desde otra maquina de la red:

http://192.168.5.19:2500/mcp

Configuracion MCP HTTP:

{
  "mcpServers": {
    "logs_pharmasuite_adasoft": {
      "url": "http://192.168.5.19:2500/mcp"
    }
  }
}

Si tu cliente solo soporta stdio, usa puente:

{
  "mcpServers": {
    "logs_pharmasuite_adasoft": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "http://192.168.5.19:2500/mcp"]
    }
  }
}

Inicializacion JSON-RPC:

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {
    "protocolVersion": "2025-06-18",
    "capabilities": {},
    "clientInfo": { "name": "local-ai", "version": "1.0.0" }
  }
}

list_log_sources

Lista fuentes y estado.

{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "list_log_sources",
    "arguments": {}
  }
}

query_logs

Busca texto y niveles.

{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "query_logs",
    "arguments": {
      "query": "timeout",
      "levels": ["error"],
      "tail": 200
    }
  }
}

get_log_stats

  "jsonrpc": "2.0",
  "id": 4,

  "params": {

    "arguments": {}
  }
}

get_latest_log_file

Resuelve el fichero real de una fuente.

{
  "jsonrpc": "2.0",
  "id": 5,
  "method": "tools/call",
  "params": {
    "name": "get_latest_log_file",
